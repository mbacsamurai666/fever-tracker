# บันทึกไข้ & ยา

เว็บแอปบันทึกการวัดไข้และการกินยาลดไข้ เน้นใช้งานบนมือถือ

- 🌡️ บันทึกอุณหภูมิ พร้อมกราฟ (เส้นไข้ 37.5°C)
- 💊 ยาลดไข้สูง — กินได้ทุก 6 ชม.
- 💊 ยาลดไข้ธรรมดา — กินได้ทุก 4 ชม.
- แสดงเวลาที่กินยาครั้งถัดไปได้ และเตือนเมื่อยังไม่ครบเวลา
- ข้อมูลเก็บใน `localStorage` ของเครื่อง · สำรอง/นำเข้าเป็นไฟล์ JSON ได้
- เพิ่มลงหน้าจอโฮมได้ (Add to Home Screen)

ไฟล์เดียว `index.html` ไม่ต้อง build — เปิดผ่าน GitHub Pages ได้ทันที

> ใช้เพื่อช่วยจำเท่านั้น ไม่ใช่คำแนะนำทางการแพทย์
